# 🤖 AI-ML — Python Fundamentals

My Python learning journey, organised as clean, commented example files — the same material I use when teaching beginners.

![Python](https://img.shields.io/badge/Python-3.x-0D1117?style=for-the-badge&logo=python&logoColor=3776AB)

## What's inside
**Python Fundamentals — Part 1**
- `firstprogram.py` — your very first Python program
- `variable.py` — variables and data types
- `comments.py` — how and why to comment code
- `arithmatics operator.py` — arithmetic operators with examples
- `sum.py` — adding numbers, step by step
- `CaseGuide.py` — naming styles (snake_case, camelCase…) explained

## Run any file
```bash
python3 "Python Fundamentals Part 1/firstprogram.py"
```
No libraries needed — pure Python 3.

## Who is this for?
Students starting Python from zero, especially BICTE / BCA / +2 learners in Nepal.
